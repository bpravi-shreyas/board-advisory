## Deployment
1. Download the final ZIP and extract it locally.
2. In GitHub repository `bpravi-shreyas/board-advisory`, upload the CONTENTS
   of this folder into the publishing branch root, not a new subfolder.
3. Replace index.html and styles.css; add enterprise-ai.html and sitemap.xml.
4. Retain all existing files and folders, especially downloads/, articles/,
   recognition/, publications/ and .nojekyll.
5. If your live repository has a CNAME file, KEEP IT unchanged. Do not delete
   or replace it with this package. The uploaded archive had no CNAME.
6. Commit changes and check GitHub Actions/Pages deployment.
7. Test homepage, enterprise-ai.html, board biography download, articles,
   recognition images, published paper, navigation and mobile menu.
8. Confirm that the published site is using the correct custom domain.
