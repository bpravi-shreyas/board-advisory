# Board Advisory Website — GitHub Pages

This repository contains a static website.

## Publish
1. Create a **public** GitHub repository named `board-advisory`.
2. Upload all files and folders in this archive to the repository root (not a nested folder).
3. In repository **Settings → Pages**, choose **Deploy from a branch**, branch `main`, folder `/ (root)`, then Save.
4. The site will be available at `https://YOUR-USERNAME.github.io/board-advisory/` after deployment completes.

## Important
- The contact form is front-end only; it may require an external form backend to receive submissions.
- Confirm redistribution permissions for the included third-party publication and ceremony photographs before making the repository public.
- GitHub Pages publishes files in a public repository, including downloadable PDFs.
